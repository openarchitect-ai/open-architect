# Working Log

Chronological, plain-language record of what happened on this project,
newest entry on top.

The four topical files organize by category (questions, answers,
evidence, tasks). This file organizes by time so the project's story
can be read linearly.

Add an entry when a skill runs, a scope or playbook change lands, a
sponsor or stakeholder decision is confirmed, or anything else worth
remembering. Skip routine edits — git history already captures those.

Each entry should read clearly to someone joining the project cold.
Plain language, not jargon.
