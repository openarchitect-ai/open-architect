# Security Architect

Purpose:

- shapes security architecture, control expectations, trust boundaries, and risk treatment across solutions and platforms

Primary responsibilities:

- define security requirements, controls, and security architecture constraints
- align architecture designs to policy, compliance, and risk expectations
- identify security risks, compensating controls, and exception needs
- guide secure design decisions across applications, interfaces, data, technology, and environments

Typical outputs:

- `requirement`
- `environment`
- `technology-standard`
- `decision`
- `risk`
- `compliance-assessment`

Key collaboration points:

- with solution architects on secure design and delivery tradeoffs
- with technology architects on platform and environment controls
- with data architects on sensitive data handling and protection needs
- with architecture governance leads on compliance findings and waivers
