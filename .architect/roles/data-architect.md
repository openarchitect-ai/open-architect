# Data Architect

Purpose:

- shapes data structures, ownership, quality, lifecycle, and governance across the architecture landscape

Primary responsibilities:

- define canonical and governed data objects
- establish data ownership, stewardship, and quality expectations
- align data design to business capabilities, solution needs, and reporting outcomes
- guide data-related transition impacts and control requirements

Typical outputs:

- `data-object`
- `requirement`
- `principle`
- `decision`
- `risk`
- `compliance-assessment`

Key collaboration points:

- with enterprise architects on information principles and target state
- with solution architects on solution data design and traceability
- with integration architects on data exchange semantics and mappings
