# Sectors

Use this folder to describe sector-specific regulatory context that changes how
architecture should be designed or governed.

Typical examples:

- financial services
- healthcare
- public sector
- critical infrastructure
- payment processing

Sector notes should help answer:

- which regulatory families are most likely to apply
- which control expectations are architecture-significant
- which roles should be involved earlier in review and approval
