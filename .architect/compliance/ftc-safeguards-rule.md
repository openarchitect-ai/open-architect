# FTC Safeguards Rule

## Regulation

- FTC Safeguards Rule: https://www.ftc.gov/legal-library/browse/rules/safeguards-rule

## Architecture Relevance

The FTC Safeguards Rule matters for covered financial institutions handling
customer information where the architecture must support a written information
security program and appropriate safeguards.

## Typical Architecture Concerns

- customer information protection
- service provider and third-party safeguards
- access control and monitoring
- incident response readiness
- governance evidence and accountability

## Useful Patterns

- `security-control-inheritance`
- `data-sharing-agreement-governance`
- `privileged-session-monitoring`
- `secrets-breach-response`
- `architecture-assurance-evidence-trail`
