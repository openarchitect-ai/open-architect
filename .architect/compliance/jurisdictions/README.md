# Jurisdictions

Use this folder to describe jurisdiction-specific regulatory context that affects
architecture decisions.

Typical examples:

- EU / EEA
- United States
- California
- United Kingdom
- country-specific data residency or critical-infrastructure obligations

Jurisdiction notes should help answer:

- which regulations may apply
- which data transfer or residency constraints matter
- which incident-reporting or supervisory obligations shape the architecture
