# HIPAA Security Rule

## Regulation

- HHS HIPAA Security Rule overview: https://www.hhs.gov/hipaa/for-professionals/security/index.html

## Architecture Relevance

The HIPAA Security Rule matters when the project creates, receives, maintains,
or transmits electronic protected health information and architecture choices
affect safeguards around confidentiality, integrity, and availability.

## Typical Architecture Concerns

- identity and access control
- audit logging and monitoring
- transmission and storage safeguards
- environment and operational controls
- risk analysis and remediation support

## Useful Patterns

- `layered-security-controls`
- `audit-and-tamper-evident-logging`
- `regulated-data-access-approval`
- `secrets-breach-response`
- `runtime-policy-enforcement`
